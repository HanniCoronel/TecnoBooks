# TecnoBooks

## 📌Projeto de Estudos em HTML e CSS📌

### Sobre o Projeto

Este projeto tem como objetivo colocar em prática conhecimentos adquiridos em HTML e CSS. Foi criado um site de venda de livros de tecnologia,
iniciando pelo mobile first. Conhecimentos aplicados:

- Header(cabeçalho) com menu hambúrguer funcional, sem a utilização de javascript.
- Banner com uma imagem de fundo no próprio input de pesquisa, utilizando CSS.
- Importação de um plugin, uma biblioteca externa, para fazer um carrossel.
- Card reforçando todo o conhecimento de flexbox.
- Criação de uma seção de tópicos "Visitados recentemente", que contém uma lista de vários assuntos sobre tecnologia.
- Criação de uma sessão de contatos com um input que tem uma imagem de fundo, que é a de um envelope.
- Footer(rodapé).
- Amplicação de tela mobile para tela e layout de tablet(1024px) utilizando media query.
- No layout do tablet deste projeto específico, foi feito outro tipo de menu, que não é o menu hambúrguer, mas que também abre quando clicamos em "CATEGORIAS".
- Footer(rodapé) alterado para telas maiores com todos os produtos da Casa do Código(utilizando as imagens e nomes divulgados pelo curso Alura).
- Criação de uma extensa lista no HTML.
- Ampliação de tela de tablet para tela Desktop(1728px ou maior) utilizando media query.
- A versão desktop alterou um pouco o header(cabeçalho), aplicando mais conhecimentos de flexbox na seção de lançamentos mais vendidos, para que o card ficasse ao lado do carrossel.


🔨**Ferramentas Utilizadas**🔨

- HTML
- CSS
- FIgma, interface do projeto disponibilizada pelo curso.
